# Vicky 资产库 · 初始版

## 在线浏览

固定网页地址：[Vicky 资产库](https://lyx1265897416-lab.github.io/Vicky-Asset-Repository/)。GitHub Pages 从 `gh-pages` 分支发布，不依赖本机服务或终端窗口。仓库与完整备份公开可访问。

网页包含全部已确认目录、序号搜索、角色图片、详情与提示词、音色、背景音乐和视频。受 Pages 站点容量限制，图片使用最大边 1280 px 的 WebP 展示副本，背景音乐使用 AAC 网页试听副本；角色音色与视频保留原字节。页面明确标注展示版，原始尺寸与生成记录继续保留，完整原文件通过页首和页尾的 Release 入口获取。

后续更新：先更新本机资产库，再执行 `python3 tools/prepare_github_pages.py`（需要 Pillow、imageio-ffmpeg）。导出到 `deployment/github-pages/public/`，保留目录中的独立 `gh-pages` Git checkout；验证后在该目录提交并推送 `gh-pages`。脚本会检查文件引用、音色字节及小于 950 MB 的发布预算，超出时阻止发布。完整备份另按下方快照流程更新，保留历史 Release。

## 本机启动与恢复

macOS 双击 `打开资产库.command`：在独立终端启动服务，确认就绪后打开 `http://127.0.0.1:8768/`。服务不依赖 Codex 会话，异常退出后 5 秒重试；保留该终端窗口，按 Ctrl+C 可停止。关闭终端、电脑关机或退出登录后需重新双击启动。

只允许本机访问，本机服务与已发布的线上网址分别运行。当前项目位于 macOS 受保护的 Documents 目录；直接使用后台登录服务会被系统拒绝读取，不能将其视为已配置成功的自启动，也不能用本机服务代替永久在线网站。

首次取回完整内容（需要安装、登录 GitHub CLI；公开仓库不需要额外成员权限）：

```sh
git clone git@github.com:lyx1265897416-lab/Vicky-Asset-Repository.git
cd Vicky-Asset-Repository
python3 tools/github_assets.py restore
python3 serve_gallery.py --port 8768
```

打开 `http://127.0.0.1:8768/`。现有页面可直接使用，不必重新生图。语音生成的本机 Python 虚拟环境不上传；已生成音频和所需模型文件都包含在快照中。macOS Finder 缓存、Python 字节码、运行锁及上传临时包同样不属于内容快照。

后续更新由用户提出后再执行。`tools/github_assets.py prepare --tag snapshot-YYYY-MM-DD` 会沿用未变化的已有内容对象，仅为新增或变更文件分包；随后提交源码/清单、创建对应草稿 Release、运行 `publish`，待全部远端哈希核验通过，再提交最终清单并发布 Release。不要删除旧 Release：最新清单可继续引用其中未变化的对象。

导出目录 `deployment/`、在线托管工程 `private-site/`、实验托管工程 `mobile-site/` 不进入内容快照，避免重复发布包和托管凭据混入；资产库本体源码、确认素材、参考、导入记录与生成元数据均按原路径备份。

## 图片生成信息（2026-09-23）

每张卡片的「详情与提示词」打开图片与生成信息：独立文生图提示词、生图模型、实际生成日期、图像尺寸；可以复制完整提示词或下载 UTF-8 文本记录。桌面并排显示，窄屏上下滚动。提示词框内的方向键用于阅读文字，不会切换图片。

本次覆盖当前全部 121 张：23 张保留原始纯文生图提示词，98 张提供按成图重建的独立文生图提示词。117 张有生成事件依据（其中 8 张为裁切资产，显示母图生成日期），4 张外部参考图日期未知。ImageGen 记录没有披露具体模型版本，因此不填写猜测的模型名称。日期按 America/Los_Angeles 显示，原始 UTC 时间保存在展开记录中。提示词整理日期与图片生成日期分开。

提示词描述当前图片的五官、发型、服装、构图、姿态、光线、色调与材质。没有进行逐张重生成相似度验证；纯文字不能保证同脸，需要严格身份一致时结合原图使用。

### 后续入库要求

1. 新资产在 `sync_role_assets.py` 确认名单中登记，同时在 [asset-generation-metadata.json](./asset-generation-metadata.json) 的 `assets` 中以相对图片路径登记生成信息。
2. 必须有完整 `text_to_image_prompt`，不得只写「保持参考图一致」或局部修改指令。原始纯文生图标为 `original_text_to_image`；参考图编辑结果需补写独立提示词并标为 `reconstructed_text_to_image`，另存 `original_prompt`。
3. 记录 `model` 名称与来源状态；工具未披露具体版本时明确 `not_exposed`，不能把调用工具的代理模型当作生图模型。完全未知填 `unknown`。
4. `generation_date` 必须来自生成记录，附时区与证据；裁切图记录母图与派生关系。没有依据时日期为 `null`，状态 `unknown`，填写 `generation_date_note`。不可用文件修改时间、入库时间代替。
5. 记录图片 SHA-256、实际尺寸、提示词整理日期与复现说明。证据存放 `metadata/evidence/`。
6. 执行 `python3 sync_role_assets.py`。同步和页面构建都会校验元数据；缺少记录或图片哈希变化会阻止发布，列出待补资产。页面构建自动生成每张图的 `metadata/records/` 文本下载文件，不覆盖元数据台账。

仅重建页面可执行 `python3 build_gallery.py`。图片路径保持稳定，已有收藏不受新增生成信息影响。

## 卡片操作与批量选择（2026-09-23）

- 每张卡片右下角「···」展开分享、下载原图、删除；图片详情标题下也有这三个按钮。
- 「批量选择」进入多选模式，支持逐张勾选、点击缩略图选择、全选当前筛选结果、批量分享、下载、删除。改变筛选或搜索会清空选择，避免操作隐藏图片。
- 单张下载原始图片；多张打包为一个 ZIP，文件名带序号以防同名覆盖，图片字节不变。
- 分享窗口可复制当前图片的直接链接（批量时每行一条），或使用系统分享面板分享链接、原图到设备支持的应用。单张图片也可复制到剪贴板，再去微信等应用粘贴；不支持时提供下载原图。图片自动预加载，原生分享由按钮点击直接触发。取消和失败不会显示已发送。localhost 链接仅本机可用，界面明确标注；未公开托管资产或虚构微信跳转。原来的 HTML 分享页已移除。
- 删除先进入「回收站」，可立即撤销，也可逐张或批量恢复；不删除磁盘源图。收藏关联保留，恢复后仍能在收藏中找到。
- 回收站使用当前浏览器同一地址的 localStorage（`vicky-character-library:trash:v1`），刷新、重建图库后保留；其他浏览器不同步，清除站点数据会恢复显示。收藏和回收站都按稳定图片 ID / 路径关联。
- 操作逻辑和样式位于 `gallery-actions.js`、`gallery-actions.css`，构建脚本自动引用；浏览器测试与 ZIP 完整性检查见 `verification/card-actions/`。
